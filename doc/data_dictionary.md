# data dictionary
##  data/raw/raw_data.csv (wide format)
one row = human abstracts + four AI-generated models

| column | type | description |
| --- | --- | --- |
| original_abstract | text | human-written  arabic abstract |
| allam_generated_abstract | text | generated by allam |
| jais_generated_abstract | text | generated by jais |
| llama_generated_abstract | text | generated by llama |
| openai_generated_abstract | text | generated by openai |
| subset | category | generation method |

## data/processed/clean_data.csv (long format)
one row = one abstract(41941 rows)

| column | type | description |
| --- | --- | --- |
| text | text | the arabic abstract |
| label | int | 0 = human, 1 = AI-generated |
| source | category | human, allam, jais, llama, or openai |
| split | category | by_polishing, from_title, from_title_and_content |
